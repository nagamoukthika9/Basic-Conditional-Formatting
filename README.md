# Task 29 – Basic Conditional Formatting

## Objective
To improve report readability by highlighting the top and bottom sales values automatically using Excel Conditional Formatting.

## Dataset
Retail Sales Dataset

## Tools Used
- Microsoft Excel

## Operations Performed
1. Imported the retail sales dataset into Excel.
2. Applied basic formatting to column headers.
3. Enabled filters for easy data analysis.
4. Applied Conditional Formatting to the Total Amount column.
5. Highlighted the top 10 values.
6. Highlighted the bottom 10 values.
7. Created a separate sheet containing the conditional formatting rules.

## Conditional Formatting Rules
| Total Amount | Top 10 values |
| Total Amount | Bottom 10 values |

## Outcome
Successfully applied automatic conditional formatting rules to identify the highest and lowest transaction amounts and improve data readability.

## Conclusion
This task helped me understand how to use Excel Conditional Formatting to highlight important values automatically instead of applying manual formatting.
